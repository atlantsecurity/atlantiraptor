# Security policy

Please report security problems in Atlantiraptor privately, not in a
public issue:

- use **Report a vulnerability** on this repository's
  [Security tab](https://github.com/atlantsecurity/atlantiraptor/security), or
- contact [Atlant Security](https://atlantsecurity.com).

Include the version (`atlantiraptor version`), what you found and how to
reproduce it. We will confirm receipt, keep you informed, and credit you
when the fix is released if you wish.

Atlantiraptor is based on Velociraptor. Vulnerabilities in code inherited
from it may also affect the upstream project; we coordinate with its
maintainers where that applies.

See [Security](https://atlantsecurity.github.io/atlantiraptor/security/)
in the documentation for how Atlantiraptor protects itself and how to
harden a deployment.
